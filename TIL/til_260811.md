# [PostgreSQL] 데이터베이스 기초 개념과 클라이언트/SQL 총정리

오늘 공부한 PostgreSQL의 기본 개념부터 관리 도구, 스키마 구조, 그리고 SQL 주요 명령어까지 한 번에 정리해 본다. 

---

## 1. PostgreSQL vs DBeaver: 서버와 클라이언트의 차이

데이터베이스를 처음 공부할 때 흔히 헷갈리는 두 개념의 차이부터 정리했다.

* **PostgreSQL (DBMS):** 실제 데이터를 저장하고 처리하는 백그라운드 **데이터베이스 서버**
* **DBeaver (GUI Client):** PostgreSQL 서버에 접속해서 시각적으로 데이터를 조회하고 조작할 수 있게 해주는 **관리 프로그램**

---

## 2. 상황별 DB 및 클라이언트 도구 추천

데이터베이스와 클라이언트 프로그램은 상황과 프로젝트 특성에 따라 적절한 도구를 선택해 사용한다.

### 💾 데이터베이스 서버 (DBMS)

* **PostgreSQL:** 복잡한 연산, 지리 정보(GIS), 데이터 무결성과 신뢰성이 매우 중요할 때
* **MySQL / MariaDB:** 읽기 작업 위주의 일반적인 웹 서비스(쇼핑몰, 블로그 등)를 구축할 때
* **SQLite:** 별도 서버 설치 없이 모바일 앱이나 데스크톱 프로그램 내부에 DB를 심을 때
* **Microsoft SQL Server (MSSQL):** Windows 및 C# / .NET / Azure 환경 기반의 기업용 프로젝트를 진행할 때
* **Oracle Database:** 금융권, 통신사, 대기업 등 대규모 시스템을 다룰 때
* **MongoDB:** JSON 형태의 비정형 데이터나 구조가 자주 바뀌는 대용량 로그를 다룰 때

### 🛠️ DB 클라이언트 (GUI)

* **DBeaver:** 무료이면서 여러 종류의 DB를 하나로 관리하고 싶을 때 (범용)
* **DataGrip:** 유료지만 스마트한 SQL 자동완성과 개발 생산성을 극대화하고 싶을 때 (JetBrains)
* **TablePlus:** 가볍고 속도가 빠르며 깔끔한 UI를 선호할 때
* **Beekeeper Studio:** DBeaver의 복잡한 메뉴 대신 심플한 오픈소스를 원할 때
* **HeidiSQL:** 윈도우 환경에서 용량이 작고 설치/실행 속도가 매우 빠른 도구가 필요할 때
* **pgAdmin:** PostgreSQL 전용 공식 도구로, DB 백업/복구 및 상세 설정을 제어할 때
* **MySQL Workbench:** MySQL 전용 공식 도구로, DB 설계(ERD) 및 관리가 필요할 때

## 3. 필수 컴퓨터 용어 정리

* **Locale (로케일):** 사용자의 국가, 언어, 문화적 환경 설정을 의미하는 표준 코드. DB에서는 문자의 정렬 기준(`Collation`), 언어 표시, 날짜 및 통화 표기 방식을 결정한다.
* **MSC (`.msc`):** *Microsoft Saved Console*의 약자 (직역: 마이크로소프트 저장된 콘솔). Windows 관리 콘솔(MMC)에서 특정 관리 기능을 실행하기 위해 저장된 파일 확장자다.
  * 예시: 서비스 관리자 (`services.msc`), 장치 관리자 (`devmgmt.msc`)

## 4. Database와 Schema의 관계 (아파트 비유)

하나의 데이터베이스(Database) 내부에는 **여러 개의 스키마(Schema)**를 생성할 수 있다. 

* **PostgreSQL 서버:** 아파트 단지
* **Database (데이터베이스):** 아파트 동 (예: 101동)
* **Schema (스키마):** 동 내부의 각 세대/구역 (예: 101호, 102호)
* **Table (테이블):** 집 안에 있는 서랍장 (실제 데이터가 저장되는 공간)

> **💡 스키마를 사용하는 이유?**
> 하나의 DB 안에서 용도별(서비스용, 통계용)로 구역을 나누거나, 사용자별 권한 분리 및 동일한 테이블 이름 충돌을 방지하기 위해 사용한다.

## 5. SQL 명령어 카테고리 요약

* **DML (Data Manipulation Language - 데이터 조작어):** `SELECT` (조회), `INSERT` (추가), `UPDATE` (수정), `DELETE` (삭제)
* **DDL (Data Definition Language - 데이터 정의어):** `CREATE` (생성), `ALTER` (구조 변경), `DROP` (완전 삭제), `TRUNCATE` (초기화)
* **DCL (Data Control Language - 데이터 제어어):** `GRANT` (권한 부여), `REVOKE` (권한 회수)
* **TCL (Transaction Control Language - 트랜잭션 제어어):** `COMMIT` (저장 확정), `ROLLBACK` (취소/원복), `SAVEPOINT` (임시 저장점)
* **주요 구문:** `WHERE` (조건), `ORDER BY` (정렬), `GROUP BY` (그룹화), `HAVING` (그룹 조건), `JOIN` (테이블 결합)
